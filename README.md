# FI – Veranschaulichungen für den Unterricht

Interaktive Lerneinheiten für Fachinformatiker, veröffentlicht über GitHub Pages:
**https://mied25.github.io/fi/**

## Inhalte

| Thema | Ordner |
|---|---|
| Medienzugriffsverfahren (CSMA/CD, CSMA/CA, RTS/CTS, Hidden/Exposed Station, Token Passing) | [`medienzugriffsverfahren/`](medienzugriffsverfahren/) |

## Aufbau

- Jede Einheit liegt in einem eigenen Ordner mit einer `index.html` (eigenständig, keine externen Abhängigkeiten).
- Die Startseite `index.html` im Hauptverzeichnis verlinkt alle Einheiten. Neue Einheit = neuer Ordner + Karte auf der Startseite + Zeile in dieser Tabelle.
